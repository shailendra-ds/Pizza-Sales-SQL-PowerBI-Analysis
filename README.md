# 🍕 Pizza Sales SQL & Power BI Analysis

## 📊 Project Overview

An end-to-end data analytics project using **SQL and Power BI** to analyze pizza sales performance and generate meaningful business insights.

The analysis covers revenue, orders, pizza quantity, pizza categories, pizza sizes, daily and monthly order trends, and best/worst-selling pizzas.

## 🎯 Project Objectives

- Analyze total revenue and sales performance
- Calculate Average Order Value (AOV)
- Analyze total pizzas sold and total orders
- Identify busiest days and months
- Analyze sales by pizza category
- Analyze sales by pizza size
- Identify best-selling pizzas
- Identify worst-selling pizzas
- Build an interactive Power BI dashboard
